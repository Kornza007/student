# 🎓 ระบบจัดการและบันทึกการฝึกงานของนักศึกษา (Internship Management System)

เว็บแอปพลิเคชันสำหรับช่วยบันทึกและติดตามการฝึกงานของนักศึกษา ออกแบบมาเพื่อแก้ปัญหาการจดบันทึกแบบเดิมที่สูญหายง่าย โดยเชื่อมโยง 3 ฝ่ายเข้าด้วยกัน: **นักศึกษา, พี่เลี้ยง และผู้ดูแลระบบ**

---

## 📌 สรุปจุดเด่นของระบบใน 3 บรรทัด (Quick Highlights)
* **ใช้งานง่าย & สวยงาม:** รองรับการเปิดบนคอมพิวเตอร์และมือถือ มีระบบสลับภาษา (ไทย/อังกฤษ)
* **จัดการข้อมูลได้ไว:** นำเข้านักศึกษาทีละหลายคนผ่านไฟล์ Excel และกดดาวน์โหลดรายงานเป็น Excel / PDF ได้
* **ปลอดภัย & มีระบบถังขยะ:** ลบข้อมูลแล้วกู้คืนได้ภายใน 60 วัน และมีบันทึกประวัติการใช้งาน (Audit Log)

---

## 🛠️ เครื่องมือที่ใช้พัฒนา (Tech Stack)

### 🎨 ฝั่งหน้าบ้าน (Frontend)
* **HTML5 / CSS3 / Bootstrap 5:** ใช้สร้างโครงสร้างและตกแต่งหน้าตาเว็บไซต์ให้สวยงาม เป็นระเบียบ
* **JavaScript (Vanilla JS):** จัดการฟังก์ชันการทำงาน และเชื่อมต่อข้อมูลกับหลังบ้าน
* **Chart.js:** สร้างกราฟและแผนภูมิสรุปสถิตินักศึกษา
* **SheetJS:** จัดการไฟล์ Excel และ CSV (นำเข้า-ส่งออก)
* **Flatpickr:** ปฏิทินเลือกวันที่แบบภาษาไทย

### ⚙️ ฝั่งหลังบ้าน (Backend & Database)
* **PHP:** ประมวลผลคำขอ (API) และตรวจสอบสิทธิ์ผู้ใช้
* **MySQL:** ฐานข้อมูลสำหรับเก็บข้อมูลผู้ใช้ บันทึกการฝึกงาน และประวัติการทำงาน
* **Apache (XAMPP):** เซิร์ฟเวอร์จำลองสำหรับรันระบบ

---

## 👥 หน้าที่ของแต่ละบทบาท (Role & Permissions)

### 1. 🧑‍🎓 นักศึกษา (Student)
* บันทึกการฝึกงานประจำวัน (ลงวันที่, รายละเอียดงานที่ทำ)
* ติดตามสถานะงานที่ส่ง (รอตรวจ, ผ่านแล้ว, ไม่ผ่าน, ส่งกลับมาให้แก้)
* ดูคำแนะนำและความคิดเห็น (Feedback) จากพี่เลี้ยง
* เช็กระยะเวลาการฝึกงานและวันที่สิ้นสุด

### 2. 🧑‍🏫 พี่เลี้ยง (Mentor)
* ดูรายชื่อนักศึกษาในความดูแลของตนเอง
* ตรวจสอบบันทึกประจำวันของนักศึกษา (อนุมัติ, ปฏิเสธ หรือสั่งแก้ไข)
* เขียนข้อเสนอแนะและประเมินผลคะแนนการฝึกงาน

### 3. 👨‍💼 ผู้ดูแลระบบ (Admin)
* จัดการข้อมูลนักศึกษาและพี่เลี้ยงทั้งหมด (เพิ่ม, ลบ, แก้ไข)
* เพิ่มรายชื่อนักศึกษาทีละหลายคนด้วยการอัปโหลดไฟล์ Excel
* ดูกราฟสรุปสถิติภาพรวม เช่น สัดส่วนสถานะการฝึกงาน, จำนวนนักศึกษาตามมหาวิทยาลัย
* ส่งออกข้อมูลรายงานเป็นไฟล์ Excel, CSV, PDF หรือรูปภาพ JPG
* ตรวจสอบประวัติการใช้งาน (Audit Logs) ดูว่าใครทำอะไรเวลาไหน
* จัดการถังขยะ (Recycle Bin) กู้คืนข้อมูลที่เผลอลบได้ภายใน 60 วัน

## 🚀 วิธีเปิดใช้งานบนเครื่อง (How to Run)

1. ติดตั้งโปรแกรม **XAMPP**
2. เปิด XAMPP แล้วกดปุ่ม **Start** ที่ **Apache** และ **MySQL**
3. วางโฟลเดอร์โปรเจกต์ไว้ที่ `C:\xampp\htdocs\lab_month_korn`
4. นำเข้าฐานข้อมูล:
   * เปิดเบราว์เซอร์ไปที่ `http://localhost/phpmyadmin`
   * สร้างฐานข้อมูลชื่อ `lab_month_korn` แล้วนำเข้า (Import) ไฟล์ `schema.sql`
5. เข้าใช้งานระบบผ่านลิงก์:
   ```text
   http://localhost/lab_month_korn
   ```
