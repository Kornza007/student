ระบบจัดการนักศึกษาและการบันทึกกาาฝึกงานของนักศึกษา

เว็บไซส์นี้ใช้สำหรับการบันทึกและติดตามการฝึกงานของนักศึกษาออกแบบมาเพื่อพี่เลี้ยงในการดูแลและประเมินทักษะ
ของนักศึกษา และadminสามารถจัดการข้อมูลร่วมกันได้

<!-- Stackที่ใช้ -->

-Backend: php , MySQL , Apacha
-Fontend: HTML, CSS, Javascript

<!-- ฟีเจอร์หลัก -->
-การแบ่งRole ที่ชัดเจนได้แก่ 1.Student 2.Mentor 3.Admin
-การแบ่งสัดส่วนหน้าที่และมุมมองของแต่ละRole ไดอย่างชัดเจน
-การนำข้อมูลเข้าExcel /CSV และการส่งออกเป็น Excel/ PDF ได้
-สามารถเพิ่มนักศึกษาโดยนำข้อมูลจากExcel ได้

<!-- สิ่งที่แต่ละRoleจะเห็นมุมของตัวเอง -->


นักศึกษา(Student)
   
   -เห็นการบันทึกงานของตัวเอง และตารางที่ส่งข้อมูลพี่เลี้ยงของตนเอง
   -สามารถแก้ไขข้อมูลและลบได้
   -เห็นสถานะของตนเอง ว่าส่งข้อมูลถึงพี่เลี้ยงหรือยัง
   -เห็นข้อความจากพี่เลี้ยงจากการแสดงความคิดเห็น
   -ระยะเวลาในการฝึกงานตั้งแต่วันแรกถึงวันสุดท้าย


พี่เลี้ยง(Mentor)

    -เห็นรายละเอียดข้อมูลของนักศึกษา ชื่อ-นามสกุล, มหาวิทยาลัย/คณะ/สาขา, ระยะเวลาการฝึกงานตั้งแต่เริ่ม-สิ่นสุด,สถานะของนักศึกษา (ฝึกอยู่,ฝึกจบแล้ว)
    -สามารถอนุมัติ/ปฏิเสธ/ส่งกลับไปแก้ไชงาน ของนักศึกษาได้และสามารถFeedbackต่อนักศึกษาได้
    

Admin

    -เห็นรายละเอียดข้อมูลของนักศึกษาได้หมด
    -จัดการข้อมูลของนักศึกษาได้หมด(ทั้งเพิ่ม,ลบ,แก้ไข)
    -จัดการข้อมูลของพี่เลี้ยง
    -เห็นบันทึกของนักศึกษาทั้งหมด
    -แสดงข้อมูลกราฟและบอร์ดสถิติของนักศึกษาในแต่ละหมวด(จำนวนนักศึกษา,สัดส่วนสถานะการฝึกงาน,ตรวจสอบการบันทึกงานในแต่ละวัน,แสดงสถิตินักศึกษาตามสถาบันศึกษา)
    -สามารถส่งออกข้อมูล Excel/CSV/PDF/JPG
    -ตรวจสอบประวัติการใช้งานในแต่ละวันและดูการเคลื่อนไหวในแต่ละRole/Userว่าทำอะไรไปบ้าง 
    -สามารถดูรายละเอียดในแต่ละวันของระบบตรวจสอบข้อมูลได้
    -สามารถกู้คืนข้อมูลได้แต่มีระยะเวลาเพียงแค่60วันที่ข้อมูลนี้จะอยู่ในระบบ
